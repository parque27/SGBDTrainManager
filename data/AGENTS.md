# AGENTS.md: rules for coding assistants working with `data/`

Context for automated assistants. Humans: read `README.md` first.

## What this folder is
- Cleaned recording of Catalan train activity, RENFE and FGC, 2026-11-01T23:00Z to 2026-11-06T23:00Z (5 Madrid weekdays, 2026-11-02 to 2026-11-06).
- Generated by a build. **Never modify, reformat or append to any file in `data/`.** To change the data, ask for a rebuild.
- Column definitions (type, unit, meaning, `links_to`, `natural_key`, example): `data/schema.csv`. Row counts and checksums: `data/manifest.csv`. Treat both as the source of truth.

## Files and natural keys
- `network/stations.csv.gz`: `station_id`.
- `network/routes.csv`: `route_id`.
- `network/trips.csv.gz`: `trip_id` (a run: `<operator>:<raw id>@<service_date>`; raw id in `source_trip_id`).
- `network/stop_times.csv.gz`: (`trip_id`, `stop_sequence`).
- `network/shapes.csv.gz`: `shape_id`. `network/tracks.csv.gz`: `way_id` (OpenStreetMap).
- `realtime/positions/<YYYY-MM-DD>.csv.gz`: (`time`, `train_id`). Five files, same columns, one table `import.positions`.
- `realtime/trip_delays.csv.gz`: (`time`, `trip_id`). `realtime/stop_arrivals.csv.gz`: (`trip_id`, `stop_sequence`).
- `realtime/cancellations.csv`: `trip_id`. `realtime/alerts.csv`: `alert_id`. `realtime/alert_targets.csv`: no key (one row per informed entity; any of `route_id`, `station_id`, `trip_id` may be set, the others empty).
- `realtime/occupancy.csv.gz`: (`time`, `train_id`, `car`), FGC only.
- `events/stops.csv.gz`: `stop_event_id`. `events/incidents.csv`: `incident_id`. `events/data_issues.csv.gz`: (`time`, `train_id`, `issue`), `train_id` empty for `failed_minute`.

## Conventions
- CSV: UTF-8 without BOM, comma, header row, `\n` line endings. `.gz` files are gzip.
- IDs: text with operator prefix (`renfe:…`, `fgc:…`, `osm:…`). Never strip the prefix.
- Times: UTC, ISO 8601 with `Z`. Observations at minute precision. `service_date`: Madrid calendar date.
- Points: `lat`, `lon`, WGS84, 6 decimals. Lines: `geometry_wkt`, WKT in lon lat order, SRID 4326.
- Units by suffix: `_s` seconds, `_kmh` km/h, `_m` metres, `_pct` percent 0–100.
- Booleans: `true` / `false`. Empty field = unknown or not applicable, never 0 or -1.
- Rows are sorted by the natural key.

## How to build tables
- Load with `data/load/load.sh` or `data/load/load.ps1` (PostGIS image `postgis/postgis:18-3.7`). This creates schema `import`: one landing table per file (positions: one table for the 5 files), typed columns, no keys, no indexes, no geometry.
- Build the real schema from `import.*` with `INSERT … SELECT`. Do not load the CSVs a second way.
- Geometry: store SRID 4326 (`ST_SetSRID(ST_MakePoint(lon, lat), 4326)`, `ST_GeomFromText(geometry_wkt, 4326)`); use EPSG:25831 (`ST_Transform(geom, 25831)`) or `geography` for metres.
- Quote the column `"end"` (reserved word) in `stops` and `incidents`.
- Check row counts against `manifest.csv` after every transformation step.
- `trip_id` and `station_id` links have small known exceptions (see `README.md`); test for orphans before adding a foreign key, and keep empty IDs as NULL.

## Quirks to respect
- `train_id` is not one physical train for FGC (it is one run; the unit is `vehicle_id`) and recurs every day for long distance. Use `trip_id` for one run.
- `position_fixed = true`: position corrected by cleaning; originals in `events/data_issues.csv.gz`. Do not undo it.
- `carried_forward = true`: the row repeats the previous minute's state. Not a stop, not new information.
- `movement`: `moving`, `stopped_station` (with `station_id`), `stopped_line`.
- Rodalies `speed_kmh` up to 350 km/h is the feed snapping to the next station early, left as published. Do not treat it as a real speed or an error.
- Incidents are interpretations: always read `evidence`. `not_reported` cancellations are low confidence and are not incidents. FGC alerts with ids `fgc:OBSERVATIONS_*` are timetable notes (connections, reserved cars): they are in `alerts` but not incidents.
- RENFE alerts first seen before 2026-11-04T16:49Z have `live = false` (frozen feed). Exclude them from live views.
- Occupancy exists only for FGC.
- Cancellation incidents can end after the window (timetabled end).
- Anything shown to users must credit the sources as in `LICENSE-DATA.md`.
